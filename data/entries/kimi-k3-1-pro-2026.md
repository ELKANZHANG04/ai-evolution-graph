## 背景

2026 年下半年，开源权重模型的参数规模与能力持续上探。Kimi K3.1 Pro 是 K3 的后训练版本，官方把它定位为「3T 级开源权重模型」，并首次把百万 token 上下文与智能体能力打包发布。

## 核心观点

官方技术博客给出的重点：编程、3D 创作、金融研究与智能体任务全面增强；Terminal-Bench 4.0 得分 65.7%，Kimi Code Bench 3.0 Long-horizon 61.2%；权重将在 11 月 4 日前放出。发布同时上线 Kimi.ai、Kimi Work、Kimi Code 与 API。

## 为什么今天还要读

它代表国产模型的两条线同时推进：能力追前沿、权重更开放。对开发者而言，「等权重放出后本地能跑成什么样」比发布日的榜单分数更值得跟踪。
