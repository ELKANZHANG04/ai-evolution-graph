# 国内上线方案（面向国内访问 + 能被百度搜到）

> 现状：GitHub Pages 已上线（https://elkanzhang04.github.io/ai-evolution-graph/），可作为**临时预览/分享**；但国内访问不稳定，百度对 github.io 抓取也弱。本文件给"主要面向国内"的完整路径。

## 一、先明确三件事

| 目标 | 靠什么 | 备注 |
|---|---|---|
| 国内能打开、速度稳 | 国内静态托管 + 备案域名 | 免备案可用平台默认二级域名 |
| 百度/搜狗/360 能搜到 | 静态 HTML 内容页 + sitemap + 主动推送 + 站点验证 | 已完成静态内容页与 sitemap，见第三节 |
| 大家愿意点/愿意传播 | 微信公众号 / 知乎 / 小红书 / B站 等内容分发 | 网站做"知识底座"，平台做"入口" |

## 二、国内托管的两条路线

### 路线 A：先免备案上线（1–2 天，推荐先做）

用国内云厂商的**静态网站托管 + 默认二级域名**（不需要备案）：

| 平台 | 说明 | 费用 |
|---|---|---|
| **腾讯云 EdgeOne Pages** | 免费静态托管 + 国内 CDN，可关联 Git 或上传 `dist`，默认域名可直接访问 | 免费额度 |
| **腾讯云 CloudBase 静态托管** | 默认域名 `*.tcloudbaseapp.com` 国内访问快；自定义域名需备案 | 有免费额度 |
| Gitee Pages | 需实名；免费版有审核/限制，适合作为镜像 | 免费/Pro |

步骤（以 EdgeOne Pages / CloudBase 为例）：
1. 注册腾讯云（微信扫码即可）→ 搜索「EdgeOne Pages」或「云开发 CloudBase」→ 创建静态网站；
2. 部署方式二选一：
   - **上传**：本地 `npm run build` 后，把 `dist/` 里的全部文件上传（保证 `index.html` 在最外层）；
   - **关联 Git**：授权 GitHub 仓库，构建命令 `npm run build`，输出目录 `dist`。
3. 得到默认域名（如 `xxx.edgeone.app` / `xxx.tcloudbaseapp.com`），用手机 4G 测试访问速度。
4. 绑定自定义域名需要**ICP 备案**（见路线 B）。

### 路线 B：正式长期（自定义域名 + 备案，2–4 周）

1. **买域名**：阿里云/腾讯云，`.com`/`.cn` 约 ¥30–100/首年。
2. **ICP 备案**（免费，个人 1–3 周）：在域名所在云厂商的备案系统提交（身份证、手机号、域名实名、拍照核验）。
3. **静态托管 + CDN**：
   - 阿里云 OSS（静态网站模式）+ CDN；或腾讯云 COS（静态网站）+ CDN；或 EdgeOne Pages 绑定已备案域名；
   - 上传 `dist/`，配置默认首页 `index.html`、404 页面（如果有）。
4. **HTTPS**：免费 DV 证书（云厂商一键申请）。
5. 之后把域名填进项目的 `site.config.json` 的 `siteUrl`，重新构建（canonical/sitemap 会自动更新）。

> 参考价格：域名 ¥30–100/年；对象存储+CDN 流量按量（个人站每月通常几元~几十元，有免费额度）。备案本身免费。

## 三、搜索收录：已经做好的技术前提

### 已完成（本地代码，等 push 后上线）
- **141 个静态内容页**：`/p/mainline/`、`/p/thoughts/`、`/p/feed/`、`/p/about/` + **每条条目一个页面** `/p/entry/<id>/`，内容包含标题/日期/摘要/为什么重要/原文/来源/关联条目，**不依赖 JS**（百度可直接读）；
- **sitemap** 自动生成 **142 个 URL**；`robots.txt` 允许抓取；
- 每页有独立 title/description/canonical/Open Graph/JSON-LD；
- **百度主动推送脚本**：`BAIDU_TOKEN=你的token npm run seo:push`（读取 sitemap 批量推送）；
- 交互版（主线/思想看板/动态/图谱）保持原样，静态页都有「在交互图谱中查看 →」入口。

### 上线后要做（需要你的账号）
1. 注册 **百度搜索资源平台** <https://ziyuan.baidu.com> → 添加站点（用最终域名或默认二级域名）→ 验证（推荐文件验证：下载 html 放到 `dist/` 根目录，或 HTML 标签验证）。
2. 提交 sitemap：`https://你的域名/sitemap.xml`；
3. 主动推送（可选但推荐）：获取 token 后执行 `BAIDU_TOKEN=... npm run seo:push`；
4. 同时提交 **搜狗搜索资源平台、360 站长平台、头条搜索**（都支持 sitemap）；
5. 百度移动适配：站点已响应式，可在百度平台提交移动适配；
6. 预期：Baidu 2–8 周开始收录，持续每日更新会加快；新站有观察期。

> 说明：若用 **GitHub Pages 域名**做百度站点，也可以验证和提交，但国内访问与抓取都偏弱；建议最终用国内托管。
