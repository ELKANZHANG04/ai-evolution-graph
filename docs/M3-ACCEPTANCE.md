## 二、最新动态（#/feed）
- [ ] 三个时间窗：最近 7 天 / 30 天 / 全部（带计数，默认 30 天）
- [ ] 卡片：日期、类型、影响力、待核对、NEW（`added_at` ≤7 天）、标题、摘要、类别、类别色边条
- [ ] 点击卡片打开详情抽屉；`?entry=` 深链可分享
- [ ] 7 天/30 天为空时显示「最近更新于 …」兜底 + 查看全部按钮
- [ ] 移动端单列、无横向溢出

## 三、全局搜索（#/search）
- [ ] 加权搜索：标题/英文标题/标签/摘要/意义/原文/思想主张/人物/场合/正文；多关键词 AND
- [ ] 高亮命中片段（`<mark>`），显示命中字段与耗时
- [ ] 组合筛选：10 类别多选、年份区间（1950–2026）、影响力区间（1–10）；全部进 URL
- [ ] 热门标签（空搜索态）、无结果空态、筛选独占（q 空）状态
- [ ] 页头搜索框 Enter 跳转 + 关键词同步；`/` 快捷键聚焦
- [ ] 移动端筛选折叠面板、单列无溢出
