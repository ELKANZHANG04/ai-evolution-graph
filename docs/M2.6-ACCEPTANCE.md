# M2.6 验收清单：思想看板做深 + 主题页合并全量数据

> 用户反馈：思想看板是最想做的部分（主题更明确、加思想概括、简化原文、突出思想本身，保留点进详情）；主线每个主题要能点进去看该主题全部事件；附属事件看不到标题不好；全量数据若已被主题页覆盖就合并。

## 一、如何验收
```bash
npm run dev   # http://127.0.0.1:5173
```
导航变为：主线 / 思想看板 / 最新动态(M3) / 关于。

## 二、思想看板（重点）
- [ ] **7 个明确主题**：01 架构与范式 / 02 规模与泛化 / 03 软件形态 / 04 世界模型 vs 语言模型 / 05 对齐与安全 / 06 智能体与交互 / 07 开源与闭源；顶部主题筛选条可收窄到单主题
- [ ] 每条主题有「关键问题」+ 主题概括，步骤按时间排序，箭头标注「命题 / 推进 / 修正 / 反驳」
- [ ] **思想优先**：卡片主标题是一句话主张（thought_claim），下面是思想概括（thought_summary），原文降级为 2 行可展开（「展开原文 ▾」）
- [ ] 16 条引文卡（全部 quote 逐字核实，来自 arXiv 摘要 / Anthropic / Google / Meta 官方材料 / GitHub 官方文档等）+ 事件/实践卡；说话人、场合、年份清楚
- [ ] 点击卡片打开详情抽屉（完整原文、正文解读、来源、关联条目）
- [ ] 移动端单列、无横向溢出

## 三、主线 v2 + 主题页（合并全量数据）
- [ ] 每个章节头右侧有「查看本章全部 N 条事件 →」，点击进入主题页（`#/chapter?ch=...`）
- [ ] 主线背景区：`另有 N 条背景事件 · 展开标题 ▾`，展开后所有附属事件**标题可见**、可点击开详情
- [ ] 主题页：全部事件列表（含主线/背景/思想），标题、日期、摘要、类别、影响力全部可见；主线/突破有标记
- [ ] 主题页三个 tab：事件列表 / 本章时间轴（面积=影响力，仅本章数据）/ 本章影响图谱（双击聚焦，仅本章数据）
- [ ] 全量数据并入主题页：导航已无「全量数据」；旧链接 `#/timeline`、`#/graph`、`?entry=` 仍兼容
- [ ] 移动端主题页单列、无横向溢出
