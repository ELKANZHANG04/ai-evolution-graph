## 1. 交付内容

- 11 个思想主题全部补成 2011→2026 的连续讨论线，每个主题 ≥7 步、最新步骤 ≥2025、架构与交互等关键主题到 2026。

- 创新雷达从 14 条收窄到 **8 条**，全部挂在主题既有路径上；同一方向只保留代表条目。
- 最新动态数据源：新增条目的 `added_at`（当前 12 条在最近 5 天内且事件日期在近 180 天内）。
- 思想看板与最新动态均按「最新在前」呈现；思想看板每个主题按时间倒序（最新在左，向右回溯）。

### 思想看板 v5（2026-10-30 二次修订）

- 主题内按时间倒序（最新在左，向右回溯）；删除命题/推进/修正/反驳标签与步骤箭头。
- 卡片标注与主线一致：年份 / 类型 / 影响力分数 / 类别 / 一句话主张 + 概括；不再有置顶、雷达、成熟度徽标。
- 删除「持续活跃 / 待补充」筛选与主题头状态徽标；保留年份活动条表达讨论连续性。
- 视觉强调只由重要性决定：importance ≥9 金色突破描边、=10 再强一档（与主线一致）。
- 创新雷达只在主题头以「新方向：…」文字聚合，不逐条标。

### 最新动态 v4（2026-10-30 二次修订）

- 不再按「事件 / 思想」拆栏，模型发布、事件、思想统一成一条「最近入库」流，按时间倒序。
- 窗口：`added_at` 最近 5 天 + 事件日期近 180 天（补录旧内容不混入）。
- 卡片标注与主线一致：日期 / 入库日期 / 类型 / 影响力分数 / 类别；创新雷达仅中性小标签。
- 页头只保留「数据更新于 + 最近 5 天入库 N」。

### 思想看板 v6：每个主题一张思维导图（2026-10-30 三次修订）

- 默认视图改为「思维导图」：11 张主题导图，根（主题）→ 子方向分支（35 个）→ 思想节点（90 个，时间倒序）。
- 叶子节点=年份/类型/影响力分数/两行标题，hover 看摘要、点击开详情；`importance ≥ 9` 金色边框。
- 支持 − / 适配 / + 缩放；长分支横向滚动；主题筛选收窄到单张导图。
- 保留「看板」视图切换（原横排卡片，信息量不丢）。
- 移动端降级为「子方向分组列表」，无横向溢出。
- 不做跨主题连线（用户明确不需要）。

### SEO 静态页（scripts/build-seo-pages.ts）

- `/p/thoughts/`：主题头增加步数/最新月份/近 18 个月/新方向聚合，雷达只标代表条目。
- `/p/feed/`：改为「最近 5 天新入库」的事件/思想两块。
